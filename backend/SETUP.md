# 주주클럽 기부 현황 백엔드 설정 (약 5분)

증권사 이체 안내와 주식기부 약정서는 **월드비전 홈페이지**에서 받습니다. 이 시트는 **캠페인 페이지의 기부 그래프용 집계**만 맡고, 개인정보(주민번호·주소·연락처·계좌 등)는 넣지 않습니다.
시트 주소는 필요 없고, 마지막에 나오는 **웹 앱 URL(…/exec)** 만 `index.html`에 넣으면 됩니다.

## 1. 시트 만들기
1. 월드비전 구글 계정으로 새 구글 시트 생성 → 이름 `주주클럽 현황`
2. **확장 프로그램 → Apps Script** → 기본 `Code.gs`를 지우고 `backend/Code.gs` 전체를 붙여넣기 → 저장

## 2. 초기 설정
1. 함수 `setup` 선택 → **실행** (권한 승인: 스프레드시트)
2. `약정`, `설정` 탭이 생기면 성공. `설정` 탭에서 **목표금액** 확인

## 3. 웹 앱 배포
1. **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 계정 **나** / 액세스 권한 **모든 사용자**
3. 나오는 **웹 앱 URL** 복사

## 4. 페이지에 연결
`index.html` 스크립트 맨 위 `const API_URL = '';` 에 URL 붙여넣기 (비워두면 샘플 그래프)

## 5. 확인
브라우저에서 `웹앱URL?action=summary` 를 열어 `{"ok":true,...}` 가 나오는지 확인

## 운영 방법 (자산기금팀)
홈페이지로 약정서가 들어오고 입고가 확인될 때마다 `약정` 탭에 **한 줄씩** 입력합니다.

| 칸 | 입력 |
|---|---|
| 접수일 | 약정서 접수일 |
| 이름 | 입고 확인용 내부 표기 (공개되지 않음) |
| 기금 / 유형 | 드롭다운 선택 |
| 종목, 수량 | 기부 주식 |
| 평가액(원) | 입고일 종가 × 수량 (입고 전에는 비워도 됨) |
| 상태 | `약정` → 입고 확인 후 `입고완료` / 취소 시 `취소` |
| 공개표시명 | **공개에 동의한 경우에만** 팀명·성명. 비우면 익명 |

- 그래프 금액은 `평가액(원)` 합계입니다. 비워두면 인원·주식 수에만 반영됩니다.
- 5분 캐시입니다. 바로 반영하려면 시트 메뉴 **주주클럽 → 기부 현황 새로고침**
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 합니다.
- 공개 API는 합계와 공개표시명만 내보냅니다. 시트는 담당자에게만 공유하세요.
