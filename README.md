# wv_asset — 주주클럽 (월드비전 임직원 주식기부 캠페인)

## 구성
- `index.html` — 단일 페이지. 기금·유형 선택 → 월드비전 홈페이지(증권사 이체 안내·약정서)로 연결, 기부 현황 그래프
- `assets/` — 메인 이미지, 로고(World Vision ↔ 후원을 멈추는 후원 교차), 기금 이미지
- `backend/Code.gs` — 구글 시트용 Google Apps Script (기부 현황 합계만 반환)
- `backend/SETUP.md` — 시트 설정·배포·운영 방법

## 동작
1. 직원이 페이지에서 기금·유형을 고르고 월드비전 홈페이지로 이동해 약정서를 작성합니다.
2. 자산기금팀이 입고를 확인하면 구글 시트 `약정` 탭에 한 줄씩 입력합니다.
3. 페이지 그래프가 Apps Script 웹 앱(`?action=summary`)에서 합계를 받아 보여줍니다.

개인정보(주민번호·주소·연락처)는 이 저장소, 페이지, 시트 어디에도 두지 않습니다.
